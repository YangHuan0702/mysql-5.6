# 主从复制执行模型

## 模块目标

该模块定义副本如何拉取、解析、落盘和执行主库产生的 binlog。

## 当前仓库参照实现

- `sql/rpl_master.cc`
- `sql/rpl_slave.cc`
- `sql/rpl_mi.cc`
- `sql/rpl_rli.cc`

## 如果你自己实现，应该怎么抽象

建议至少分成三条链：

- IO 线程：拉取 binlog
- Relay Log 子系统：中转与持久化
- SQL 线程：回放执行

## 核心数据结构

- `MasterInfo`
- `RelayLogInfo`
- `ApplierContext`

## 关键流程

1. 从主库拉取 binlog
2. 写入 relay log
3. SQL 线程顺序回放
4. 更新复制位点与 GTID 集合

## 工程实现建议

- 第一版先做单线程 apply
- 重放错误语义要明确定义
- relay log 必须可恢复

## 最小可用版本

- 单主单从
- 单线程 apply
- relay log 恢复

## 继续演进方向

- 并行复制
- 事务依赖分析
- 复制延迟诊断
